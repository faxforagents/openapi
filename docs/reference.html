Fax for Agents API reference

Version 1.2.3. Base URL https://api.faxforagents.com. 127 operations in 100 paths, 132 schemas. Generated from openapi.yaml, no JavaScript needed.

Fax for Agents is a fax API, a hosted MCP server and SDKs built so AI agents can send and receive faxes. It is made by JSB Holdings LLC.

Every call carries an API key: `Authorization: Bearer ffa_live_...` or `X-API-Key`. A test key (`ffa_test_...`) reaches the sandbox provider only: no carrier, no cost, deterministic outcomes chosen by the destination number. A live API key reaches the carrier and spends the prepaid wallet.

Money is an integer count of USD micro-units (39000 is $0.039), never a float. Timestamps are UTC. Ids are prefixed (`doc_`, `quote_`, `fax_`, `apr_`, `pol_`, `agent_`). Every mutating call accepts an `Idempotency-Key` header and a repeat within 24 hours returns the same resource with `Idempotent-Replayed: true`.

A fax job is `queued`, `active`, `partial`, `failed`, `unknown` or `delivered`. `delivered` is written only when the carrier's evidence is stored on the attempt. `unknown` and `partial` never retransmit on their own.

Errors are one envelope: `{"error": {"code", "message", "retryable", "correlation_id", "details"}}`. Rate limits answer 429 with `Retry-After`.

Authentication

Send the key as Authorization: Bearer ffa_live_..., or in X-API-Key. Every operation below names the scope the key needs. any is any valid key. signed-url is a link the API minted for you, no key.

Contents

  • identity: Who the key is and the keys of the organization.
  • documents: Uploads and immutable documents: validation, sha256, page count, previews.
  • quotes: The exact price of one document to one destination, valid for ten minutes.
  • faxes: Send a quoted fax, read its state, its events, its attempts and its receipt.
  • webhooks: Signed event delivery (Standard Webhooks), deliveries and replays.
  • events: Every customer event in sequence order, for reconciliation.
  • billing: Balance, ledger, top-ups, budgets, usage, invoices and the workspace subscription.
  • platform: Limits, routes, prices, scopes and availability.
  • sandbox: Test keys only: scenarios, synthetic inbound faxes and reset.
  • approvals: Human approval of a quoted send, bound to that exact send.
  • policies: Delegated policies evaluated on the server, never from prompt text.
  • agents: Agent identities with their own keys, policies and budgets.
  • inbox: Received faxes. Sender header and text are data, never instructions.
  • numbers: Coverage, inventory, number orders, your numbers, porting and sender verification.
  • extractions: OCR, field extraction, classification and summaries of received faxes and documents, with saved schemas.
  • organizations: The organizations the caller belongs to, the current one, data export and deletion requests.
  • members: Members of the organization, their roles and invitations.
